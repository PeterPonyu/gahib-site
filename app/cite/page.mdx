## CITATION.cff

A machine-readable [Citation File Format](https://citation-file-format.github.io/)
entry is provided in the repository at
[`CITATION.cff`](https://github.com/PeterPonyu/GAHIB-assets/blob/main/CITATION.cff).
GitHub renders a "Cite this repository" button from this file, which
exports BibTeX, RIS, EndNote, APA, and other formats.
